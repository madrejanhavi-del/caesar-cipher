# Caesar Cipher Encryption Tool 🔐

A Python-based Caesar Cipher tool developed as part of my Cybersecurity Internship at CodeOrbit Tech.

## 📌 Project Overview

This project implements the Caesar Cipher technique to encrypt and decrypt text using a user-defined shift value (key).

## ✨ Features

- Accepts a message from the user.
- Allows the user to enter a shift value.
- Encrypts text using the Caesar Cipher algorithm.
- Decrypts the encrypted message.
- Preserves uppercase and lowercase letters.
- Keeps spaces and special characters unchanged.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Code Editor:** Visual Studio Code
- **Version Control:** GitHub

## ⚙️ How to Run

1. Install Python on your system.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the integrated terminal.
5. Execute the following command:

```bash
python caesar_cipher.py
```

6. Enter your message and shift value when prompted.
7. View the original, encrypted and decrypted messages.

## 💻 Sample Output

```text
Enter your message: Hello World
Enter shift value: 3

---------- CAESAR CIPHER ----------
Original message: Hello World
Encrypted message: Khoor Zruog
Decrypted message: Hello World
```
